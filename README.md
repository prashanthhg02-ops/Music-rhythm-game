# Neon Pulse

A self-contained browser rhythm game. No dependencies or build step required.

## Play

Open [index.html](./index.html) in a modern browser and select **Start the beat**. Allow audio playback if your browser prompts you.

## Controls

- Press **D**, **F**, **J**, or **K** to hit the matching lane.
- On touch devices, tap a lane.
- Aim for the judgment line: **Perfect** is within 60 ms; **Good** is within 150 ms.
- Missed notes break your combo. Your score, accuracy, rank, and best combo appear at the end.

The beat is synthesized in the browser using the Web Audio API. The game is implemented with HTML, CSS, and JavaScript in `index.html`.
